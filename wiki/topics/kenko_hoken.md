## 概要
健康保険の給付内容・任意継続制度、後期高齢者医療制度の被保険者要件・一部負担金割合が頻出。退職後の医療保険の選択肢（任意継続・国民健康保険・家族の扶養）を整理する。

## 重要ポイント

### 傷病手当金の退職後継続給付
| 要件 | 内容 |
|------|------|
| 被保険者期間 | 資格喪失日の前日まで**継続して1年以上**の被保険者期間 |
| 支給期間 | 支給開始日から通算して**1年6ヶ月**を限度 |
| 条件 | 資格喪失時に傷病手当金を受給中または受給できる状態 |

- 「2ヶ月以上」では不足→**1年以上**が正しい（2025.09問3）

### 任意継続被保険者
| 項目 | 内容 |
|------|------|
| 加入期間 | 資格喪失日から最長**2年間** |
| 保険料 | **全額自己負担**（在職中は労使折半→退職後は全額） |
| 保険料上限 | 標準報酬月額の上限（標準報酬月額の平均額）で計算 |
| 申請期限 | 資格喪失日から**20日以内** |

### 後期高齢者医療制度
| 項目 | 内容 |
|------|------|
| 対象年齢 | **75歳以上**（一定の障害は65歳以上） |
| 一部負担金割合 | 現役並み所得者：**3割**、一定以上所得者：**2割**、それ以外：**1割** |
| 保険者 | 都道府県単位の後期高齢者医療広域連合 |

- 「70歳で後期高齢者医療制度へ移行」は誤り→**75歳**（2025.09問3）
- 「所得にかかわらず1割」は誤り→**所得により1〜3割**（2025.09問3）

### 医療費の自己負担の仕組み
| 年齢 | 医療機関窓口での負担 |
|------|-----------------|
| 小学校就学前 | 2割 |
| 小学校就学後〜69歳 | 3割 |
| 70〜74歳 | 2割（現役並み所得者は3割） |
| 75歳以上 | 1〜3割（所得による） |

### 高額療養費制度
- 一般的な所得区分（年収約370〜770万円）：月の自己負担上限 **80,100円＋（医療費−267,000円）×1%**
- 多数回該当：44,400円（同一世帯で1年間に4回目以降）

## 頻出パターン

### パターン1：退職後の傷病手当金継続
- 継続受給の要件：資格喪失前**1年以上**の被保険者期間（2ヶ月では不足）
- 「2ヶ月以上」は任意継続の最低被保険者期間（混同しない）

### パターン2：任意継続の保険料
- **全額自己負担**（在職中は事業主と折半だったが退職後は全額）
- 上限は退職時の標準報酬月額と、全被保険者の標準報酬月額の平均額の低い方

### パターン3：後期高齢者医療制度への移行年齢
- **75歳**（70歳は誤り）
- 70〜74歳は引き続き健康保険or国保の被保険者

### パターン4：後期高齢者の一部負担金
- 所得により1割・2割・3割（一律1割ではない）
