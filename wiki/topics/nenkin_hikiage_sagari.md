## 概要
老齢基礎年金・老齢厚生年金は原則65歳受給開始だが、60〜64歳に繰り上げ（減額）または66〜75歳に繰り下げ（増額）ができる。

## 重要ポイント

### 繰上げ支給
| 項目 | 内容 |
|------|------|
| 対象 | 老齢基礎年金・老齢厚生年金（同時に請求が原則） |
| 減額率 | 1ヶ月あたり0.4%（1962年4月2日以後生まれ） |
| 計算 | 例：62歳6ヶ月で請求 → 65歳-62歳6ヶ月=30ヶ月 → 30×0.4%=12%減額 |
| 注意点 | ①老齢厚生年金繰上げ請求時は老齢基礎年金も同時に申請必要<br>②繰上げ後は在職老齢年金の対象<br>③寡婦年金の受給権消滅<br>④障害年金への影響あり<br>⑤加給年金：繰上げ時も加算されるが、繰上げ減額はされない |

### 繰下げ支給
| 項目 | 内容 |
|------|------|
| 対象 | 老齢基礎年金・老齢厚生年金（別々に申請可） |
| 増額率 | 1ヶ月あたり0.7%（最大75歳まで繰下げ→最大84%増額） |
| 上限 | 75歳（2022年改正で70歳→75歳に延長） |
| 注意点 | ①遺族厚生年金の受給権者は老齢厚生年金の繰下げ不可<br>②加給年金：繰下げ期間中は加算されない（増額対象外）<br>③老齢基礎年金と老齢厚生年金は別々に繰下げ可能 |

### 繰上げと繰下げの比較
| | 繰上げ | 繰下げ |
|--|-------|-------|
| 請求時期 | 60〜64歳 | 66〜75歳 |
| 増減率 | ▲0.4%/月 | +0.7%/月 |
| 老基・老厚の同時性 | 同時申請が原則 | 別々に可 |
| 障害への影響 | 障害年金請求不可になる場合あり | なし |

## 頻出パターン

### パターン1：繰下げの不可条件
- **遺族厚生年金の受給権者→老齢厚生年金の繰下げ不可**（2025.01問4）
- 遺族基礎年金は関係なし

### パターン2：加給年金と繰上げ・繰下げ
- **繰下げ時：加給年金は繰下げ期間中加算されない（増額対象外）**（2025.01問4選択肢4が不適切）
- 繰上げ時：加給年金は支給されるが、繰上げによる減額の対象外

### パターン3：繰上げの減額計算
- 1962年4月2日以後生まれ：0.4%/月
- 例：62歳6ヶ月=30ヶ月繰上げ→0.4%×30=12%減額（2025.05問5選択肢2）

### パターン4：寡婦年金と繰上げ
- 老齢基礎年金の繰上げ請求→**寡婦年金の受給権消滅**（2025.05問5選択肢3）
