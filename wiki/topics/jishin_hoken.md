## 概要
地震保険は火災保険に付帯して契約する損害保険。保険料率は所在地と建物構造によって決まる。火災保険の契約期間は2024年以降最長5年に短縮。

## 重要ポイント

### 地震保険の基本
| 項目 | 内容 |
|------|------|
| 付帯方式 | 火災保険に**付帯**して契約（単独加入不可） |
| 対象 | 居住用建物・家財（工場・事務所は対象外） |
| 保険金額 | 火災保険の保険金額の**30〜50%**の範囲 |
| 上限 | 建物5,000万円、家財1,000万円 |
| 補償対象 | 地震・噴火・津波による損害 |
| 火災との関係 | 地震を原因とする火災は**地震保険**が対応（火災保険は不可） |

### 地震保険料率の決まり方
- **所在地（都道府県）** によって異なる → リスクが高い地域ほど保険料率が高い
- **建物構造**（木造・鉄筋コンクリート等）によって異なる
- 「保険料率は全国一律」「所在地によって異ならない」は**誤り**

### 地震保険料控除
| 項目 | 内容 |
|------|------|
| 所得税 | 支払保険料全額（上限50,000円） |
| 住民税 | 支払保険料×1/2（上限25,000円） |
| 対象 | 居住用建物・家財の地震保険料のみ |

### 損害認定区分（2017年改正）
| 区分 | 支払割合 |
|------|---------|
| 全損 | 100% |
| 大半損 | 60% |
| 小半損 | 30% |
| 一部損 | 5% |

### 火災保険の契約期間
- **2024年10月以降**：最長**5年**（従来の10年から短縮）
- 「最長10年」は誤り（2024年以降は不正確）

### 火災保険の補償対象
| 損害原因 | 火災保険 | 地震保険 |
|----------|---------|---------|
| 失火による火災 | ○ | × |
| 地震による火災 | × | ○ |
| 落雷・爆発 | ○ | × |
| 風・水・ひょう災 | ○（特約や選択制あり） | × |

## 頻出パターン

### パターン1：地震保険料率と所在地
- 地震保険料率は**所在地によって異なる**（2025.05問17）
- 「所在地によって異ならない」は誤り

### パターン2：火災保険の最長期間
- 2024年以降は最長**5年**（2025.01問17）
- 「最長10年」は誤り

### パターン3：地震起因の火災
- 地震・噴火・津波が原因の火災損害 → 火災保険ではなく**地震保険**が対応
- 火災保険は地震起因の火災を補償しない

### パターン4：地震保険は単独加入不可
- 必ず**火災保険に付帯**して契約
- 単独での地震保険契約は不可
