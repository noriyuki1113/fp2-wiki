## 概要
FPが業務を行う際に遵守すべき関連法規と、各士業の独占業務との境界線。
「無償・一般的な説明・試算」はOK、「有償・具体的・代行」は各士業登録が必要。

## 重要ポイント

### OK（登録不要）な行為
| 行為 | 根拠 |
|------|------|
| 年金の繰上げ・繰下げ受給額の試算・説明 | 具体的な裁定請求手続き代行でなければ社労士登録不要 |
| 生命保険の一般的な活用方法の説明 | 特定商品の勧誘・媒介でなければ保険募集人登録不要 |
| 景気動向・企業業績の情報提供 | 投資助言・代理業に該当しない |
| 具体的な相続税額の計算（教育目的） | 有償での税務代理・申告書作成は税理士のみ |
| 相続人への税理士紹介 | これはOK |

### NG（登録が必要）な行為
| 行為 | 必要な登録 |
|------|------------|
| 公的年金の裁定請求手続きの代行（有償） | 社会保険労務士 |
| 確定申告書の作成代行（有償） | 税理士 |
| 投資のタイミングを有償で助言（個別銘柄） | 金融商品取引業者 |
| 遺産分割協議の代理（有償） | 弁護士 |
| 遺言書・契約書の作成代理 | 弁護士・司法書士 |
| 生命保険の募集・勧誘（有償契約） | 生命保険募集人 |

### FPに関連する主要法律
- **弁護士法**：法律事務の独占（代理・法律相談・書類作成）
- **税理士法**：税務代理・税務書類作成・税務相談の独占
- **社会保険労務士法**：社会保険・労働保険の申請代行・相談
- **金融商品取引法**：有価証券の売買・投資助言の規制
- **保険業法**：保険の募集・販売の規制

## 頻出パターン

### パターン1：「○○登録を受けていないFPが〜した」
→ その行為が各士業の独占業務に当たるか否かを判断する
→ 「試算・説明・一般的情報提供」はほぼOK
→ 「有償での代行・具体的判断・申請手続き」はNG

### パターン2：年金に関する相談
- 年金額試算・繰上げ繰下げの説明 → OK（社労士不要）
- 年金裁定請求手続きの代行（有償） → NG（社労士必要）

### パターン3：税金に関する相談
- 税制の一般的説明・試算 → OK（税理士不要）
- 具体的な申告書の作成代行・確定申告代行（有償） → NG（税理士必要）
- 税理士の紹介 → OK
