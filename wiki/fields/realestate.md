# 不動産（realestate）

## 分野概要
不動産の取引・登記・法規・税金・有効活用を扱う。宅地建物取引業法・都市計画法・建築基準法などの法規と、不動産取得・保有・譲渡に関する税務が頻出。

## 主要論点

### 不動産の基礎
- **不動産の調査**：登記事項証明書（表題部・権利部甲区・乙区）、公図、地積測量図
- **価格の種類**：公示価格・基準地標準価格・路線価（公示価格の80%）・固定資産税評価額（70%）
- **不動産登記**：対抗要件、登記の種類（仮登記・本登記）

### 宅地建物取引業法
- 宅建業者の免許、取引士の設置義務（5人に1人）
- 重要事項説明（契約前、取引士が記名押印・説明）
- 手付金の制限（売買価額の20%以内）
- クーリングオフ（事務所等以外で契約、8日以内）

### 都市計画法
- 市街化区域・市街化調整区域・非線引き区域
- 用途地域：住居系（8種）・商業系（2種）・工業系（3種）
- 開発許可：市街化区域1,000m²以上（三大都市圏500m²以上）

### 建築基準法
- **接道義務**：幅員4m以上の道路に2m以上接する
- **建蔽率**・**容積率**の計算
- **セットバック**：幅員4m未満の道路（2項道路）は道路中心から2m後退
- 用途制限、防火・準防火地域の規制

### 不動産の税金
| 税目 | ポイント |
|------|----------|
| 不動産取得税 | 取得価額×3%（住宅・土地）、新築住宅の軽減 |
| 固定資産税 | 評価額×1.4%、住宅用地の特例（小規模1/6、一般1/3） |
| 都市計画税 | 評価額×0.3%、市街化区域内のみ |
| 登録免許税 | 所有権移転：土地2%、建物2%（軽減あり） |
| 印紙税 | 売買契約書・消費貸借契約書に課税 |

### 不動産譲渡の税金
- 短期（所有5年以下）：39.63%（所得税30%＋住民税9%＋復興税0.63%）
- 長期（所有5年超）：20.315%（所得税15%＋住民税5%＋復興税0.315%）
- 居住用財産の3,000万円特別控除、買換え特例

### 不動産の有効活用
- 自己建設・等価交換・定期借地権・賃貸管理委託
- 定期借地権の種類：一般定期借地権（50年以上）・事業用定期借地権（10〜50年）・建物譲渡特約付借地権（30年以上）
