# タックスプランニング（tax）

## 分野概要
所得税・住民税・法人税・消費税の仕組みと計算、各種控除・特例の適用要件を扱う。FP2級では特に所得税の計算フローと各種控除が頻出。

## 主要論点

### 所得税の基本
- **10種類の所得**：利子・配当・不動産・事業・給与・退職・山林・譲渡・一時・雑
- **総合課税と分離課税**（申告分離・源泉分離）
- **損益通算**：通算できる所得・できない所得、繰越控除（純損失3年、雑損3年）

### 所得税の計算フロー
1. 各所得の計算
2. 損益通算
3. 所得控除の適用 → 課税所得
4. 税率適用（超過累進税率）
5. 税額控除の適用 → 納付税額

### 所得控除（主要）
| 控除 | ポイント |
|------|----------|
| 基礎控除 | 最大48万円（合計所得2,400万円以下） |
| 配偶者控除 | 最大38万円、配偶者の合計所得48万円以下 |
| 扶養控除 | 一般38万円、特定63万円、老人（70歳以上）48万円 |
| 社会保険料控除 | 全額控除 |
| 生命保険料控除 | 各区分最大40,000円、合計最大120,000円 |
| 地震保険料控除 | 最大50,000円 |
| 医療費控除 | （実際の医療費−10万円）または所得の5% |
| 寄附金控除 | （寄附金−2,000円）を控除 |
| 雑損控除 | 損失額−所得の10%、または災害関連支出−5万円 |

### 税額控除（主要）
- 住宅借入金等特別控除（住宅ローン控除）
- 配当控除
- 外国税額控除

### 給与所得控除
収入に応じた概算控除。最低55万円、上限195万円（収入850万円超）。

### 退職所得
（収入金額−退職所得控除額）× 1/2
退職所得控除：勤続20年以下は40万円×年数、20年超は800万円＋70万円×（年数−20年）

### 確定申告
- 原則不要なケース：給与収入2,000万円以下で1か所から給与のみ
- 必要なケース：副業所得20万円超、医療費控除等の適用希望、住宅ローン控除初年度

## 頻出数値
| 項目 | 数値 |
|------|------|
| 所得税率（最低） | 5%（195万円以下） |
| 所得税率（最高） | 45%（4,000万円超） |
| 住民税率 | 一律10% |
| 消費税率 | 標準10%、軽減8% |
