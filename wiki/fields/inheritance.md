# 相続・事業承継（inheritance）

## 分野概要
相続・贈与に関する民法・税法の規定と、事業承継の手法を扱う。法定相続分・遺留分・相続税の計算・各種特例が頻出。

## 主要論点

### 相続の基礎（民法）
- **相続人の範囲と順位**：
  - 常に相続人：配偶者
  - 第1順位：子（代襲相続あり→孫）
  - 第2順位：直系尊属（父母・祖父母）
  - 第3順位：兄弟姉妹（代襲相続あり→甥・姪のみ）
- **法定相続分**：
  - 配偶者＋子：1/2・1/2
  - 配偶者＋直系尊属：2/3・1/3
  - 配偶者＋兄弟姉妹：3/4・1/4
- **遺留分**：兄弟姉妹には無し。直系尊属のみ相続は1/3、それ以外は1/2（法定相続分の1/2）

### 遺言
- 種類：自筆証書遺言（全文自書・日付・押印）・公正証書遺言・秘密証書遺言
- 自筆証書遺言は家庭裁判所の検認が必要（法務局保管を除く）
- 遺言は最新のものが優先

### 相続税
- **課税遺産総額**：（正味遺産額）−（基礎控除：3,000万円＋600万円×法定相続人数）
- **計算手順**：
  1. 課税遺産総額を法定相続分で按分
  2. 各人の取得額に税率適用（10〜55%超過累進）
  3. 合算して相続税総額
  4. 実際の取得割合で按分→各人の税額
  5. 税額控除を適用

### 主な税額控除
| 控除 | 内容 |
|------|------|
| 配偶者の税額軽減 | 法定相続分または1億6,000万円のいずれか多い額まで非課税 |
| 未成年者控除 | （18歳−相続時の年齢）×10万円 |
| 障害者控除 | （85歳−相続時の年齢）×10万円（特別障害者は20万円） |
| 相次相続控除 | 10年以内に2回相続が発生した場合 |

### 小規模宅地等の特例
| 種類 | 面積上限 | 減額割合 |
|------|----------|----------|
| 特定居住用宅地等 | 330m² | 80% |
| 特定事業用宅地等 | 400m² | 80% |
| 貸付事業用宅地等 | 200m² | 50% |

### 贈与税
- **暦年課税**：年110万円基礎控除、超過分に10〜55%税率
- **相続時精算課税**：累計2,500万円まで非課税（110万円の基礎控除は別途適用）、贈与者60歳以上・受贈者18歳以上の推定相続人等
- **主な非課税制度**：教育資金一括贈与（1,500万円）・結婚・子育て資金贈与（1,000万円）・住宅取得等資金贈与

### 事業承継
- 自社株の評価：類似業種比準価額・純資産価額・配当還元価額
- 事業承継税制：非上場株式の贈与税・相続税の納税猶予・免除

## 頻出数値
| 項目 | 数値 |
|------|------|
| 相続税基礎控除 | 3,000万円＋600万円×法定相続人数 |
| 贈与税基礎控除 | 110万円/年 |
| 相続時精算課税 特別控除 | 累計2,500万円 |
| 配偶者の税額軽減 | 法定相続分 or 1億6,000万円の大きい方 |
